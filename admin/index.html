🔑 관리자 열쇠 등록

만든 사람에게 받은 GitHub 열쇠(토큰)를 넣고, 이 기기에서 사용할 관리자 비밀번호를 정해주세요.
열쇠는 비밀번호로 안전하게 암호화되어 이 기기에만 보관돼요.

🔒 관리자 화면 열기

이 기기에 저장된 열쇠를 풀기 위해 관리자 비밀번호를 입력해 주세요.

      기록을 누르면 그때의 사이트 모습을 미리 볼 수 있어요.

      지난 기록을 불러오는 중…

        📖 관리자 화면 도움말

        🔑 처음 열쇠 넣기

        홈페이지를 만든 사람에게 받은 관리자 열쇠와 내가 쓸 비밀번호(4자 이상)를 넣으면 안전하게 잠가 보관해요. 다음부터는 비밀번호만 넣으면 편하게 열려요.

        ✏️ 글·사진 고치기

        왼쪽(휴대폰은 ≡ 버튼) 메뉴에서 페이지를 고르면, 고칠 수 있는 칸이 차례대로 나와요. 칸에 적고 다른 곳을 누르면 바로 이 기기에 임시 저장돼요. 사진은 사진 바꾸기를 눌러요. 각 묶음의 어디에 보이나요?를 누르면 홈페이지에서 그 부분을 보여줘요.

        🚀 사이트에 반영하기

        고친 내용을 손님들에게 보여주려면 맨 위 오른쪽 사이트에 반영하기 버튼(맨 아래 오른쪽)을 눌러주세요. Render 등의 인터넷 사이트가 새 화면을 만드는 데 1~2분 정도 걸릴 수 있어요.

        ⏪ 지난 모습으로 되돌리기

        실수로 잘못 고쳤을 때는 메뉴의 지난 모습을 눌러보세요. 이전에 저장된 기록(최대 30개) 중 원하는 시점을 골라 언제든 안전하게 되돌릴 수 있어요.

        ⚠️ 다른 사람이 먼저 고쳤다고 나올 때

        다른 컴퓨터나 사람이 먼저 새 내용을 올렸을 때는 내용이 엉키지 않도록 알려줘요. 화면을 새로고침하여 최신 내용을 먼저 확인한 뒤 다시 고쳐주세요.

        ⏳ 열쇠 기간이 끝났을 때

        열쇠가 맞지 않거나 유효기간이 끝났다는 안내가 나오면, 홈페이지를 만든 사람에게 새 열쇠를 만들어 달라고 요청해 주세요.

        🔒 비밀번호를 잊으셨나요?

        이 기기에 저장된 열쇠를 지우고 처음부터 다시 등록할 수 있어요. 지운 뒤에는 홈페이지를 만든 사람에게 열쇠를 다시 받아야 해요.
